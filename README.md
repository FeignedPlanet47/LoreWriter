# Novel Forge

MVP Android-приложения для написания интерактивных новелл на Kotlin и Jetpack Compose.

## Что реализовано

- несколько проектов-новелл;
- визуальный редактор графа с перетаскиванием узлов;
- типы узлов: начало, сцена, диалог, действие, выбор, условие и концовка;
- произвольные переходы между узлами;
- подписи вариантов выбора;
- локальное хранение через Room;
- MVVM + Clean Architecture;
- Hilt для внедрения зависимостей;
- режим прохождения истории;
- проверка недостижимых узлов, отсутствующих переходов, некорректных выборов и циклов;
- экспорт полного сценария в TXT;
- технический экспорт в JSON.

## Модули

- `domain` — модели, интерфейс репозитория и use cases;
- `data` — Room, DAO, сущности и реализация репозитория;
- `app` — Compose UI, ViewModel, навигация и Hilt-конфигурация.

## Запуск

1. Откройте папку проекта в Android Studio.
2. Используйте JDK 17.
3. Установите Android SDK 36.
4. Выполните Gradle Sync. При первом запуске wrapper загрузит Gradle 8.13 и проверит SHA-256 дистрибутива.
5. Запустите модуль `app`.

## Как пользоваться

1. Создайте новеллу.
2. Нажмите `+`, добавьте сцены и выборы.
3. Перетащите карточки на холсте.
4. Откройте карточку и добавьте переходы к другим узлам.
5. Нажмите кнопку Play для тестового прохождения.
6. Кнопка проверки показывает ошибки структуры.
7. Кнопки TXT и JSON создают экспортируемые файлы через системный выбор папки.

## Проверка

Доменный слой содержит unit-тест валидатора. Экспорт TXT/JSON дополнительно проверен на тестовом графе. Полная Android-сборка требует установленного Android SDK 36.

Подробное разделение слоёв описано в `ARCHITECTURE.md`.
